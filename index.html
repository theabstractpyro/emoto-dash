eMoto Dash

Connect to your Fardriver controller over Bluetooth.

This browser has no Web Bluetooth. Use Chrome on Android, served over HTTPS.

Tip: the app can connect automatically every time it opens. Set it up under Settings → Auto-connect when the app opens.

Settings

Auto-connect when the app opens

  1. Tap Copy Chrome setting link below.
  2. Open a new Chrome tab, paste it into the address bar and press Enter.
  3. Set Use the new permissions backend for Web Bluetooth to Enabled.
  4. Tap Relaunch at the bottom of Chrome, then reopen eMoto Dash.
chrome://flags/#enable-web-bluetooth-new-permissions-backend

Chrome does not allow web pages to open chrome:// settings directly, so the link has to be pasted.
